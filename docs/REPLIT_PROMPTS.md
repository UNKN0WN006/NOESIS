# Replit & UI Prompts for ThreatLens AI

## UI design brief (for designers or Replit design assistant)

Design a clean, dark-themed dashboard for 'ThreatLens AI' showing:
- Large Exploitability Score
- Risk Heatmap
- High-risk files list

Tone: professional, enterprise-ready, no generic 'AI' stock imagery. Supply Figma mock or PNG and SVG icons.
