Demo script — NOESIS (ThreatLens AI)

1. Intro (15s)
- One-liner problem: "Static scanners miss architecture-level threats." 
- What NOESIS does: repository-level architectural threat modeling using IBM Bob.

2. Setup (10s)
- "Enter public GitHub repo URL and start analysis."

3. Analysis (90s)
- Show Loading page: staged phases (clone → map → trace → score)
- Point out live log lines and stage names
- When complete, land on Dashboard

4. Dashboard walkthrough (90s)
- Show Exploitability Score (interpretation)
- Show Risk Heatmap and explain one factor
- Open Architecture map and highlight risky module
- Drill into a privilege issue and show the suggested refactor
- Show file-level risk list and downloadable Bob export

5. Close (20s)
- Explain business value: faster, architecture-aware reviews, audit trail
- Call to action: "See bob-exports/ for Bob session transcripts and JSON"

Notes
- Keep narration concise and evidence-focused. 
- Avoid generic AI buzzwords; use terms: "architectural risk", "privilege boundary", "data flow".
